# Flutter Harness Lab

Disposable, public integration test project for
[Flutter Harness](https://github.com/halsab/flutter-harness).

## Branch contract

- `main`: default starter generated by the official Flutter SDK (Android, iOS, Web), without application-specific changes.
- `app`: initially **identical to `main`**. It is a sandbox for functionality implemented by the agent during harness testing.

The branches are created/populated by
[`scripts/bootstrap-lab.sh`](https://github.com/halsab/flutter-harness/blob/main/scripts/bootstrap-lab.sh)
**on the owner's MacBook**, using its actual Flutter SDK. This preserves
genuine SDK-generated Android/iOS/Web templates instead of hand-maintained
copies. Before the first bootstrap run, this repository contains only this
placeholder README.

To initialize, clone the harness repository and execute:

```bash
cd flutter-harness
bash scripts/bootstrap-lab.sh
```

Do not modify the `main` starter with harness source code. For reproducible
end-to-end evaluations, create a fresh feature branch from the clean `main`
commit. The `app` branch may evolve through agent-driven work and PRs, but
must not be used as the baseline for a fresh-start evaluation.

**Out of scope for v0:** installing into or migrating existing Flutter applications.
