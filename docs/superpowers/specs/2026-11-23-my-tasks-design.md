# «Мои задачи» — краткий дизайн

## Назначение

Заменить стартовый экран-счётчик Flutter-приложения простым личным списком задач. Пользователь должен добавлять задачи, отмечать их выполненными и удалять; список сохраняется между перезапусками приложения.

## Цели и ограничения

- Поддержать Android, iOS и Web согласно профилю `mobile-web`.
- Хранить данные только локально; без аккаунтов, сервера и межустройственной синхронизации.
- Оставить интерфейс небольшим и понятным: ввод задачи, список задач и действия выполнения/удаления.
- Не добавлять даты, категории, приоритеты или совместную работу.

## Подходы

- **`shared_preferences` и JSON — выбранный подход.** Достаточен для небольшого списка, прост в реализации и подходит целевым платформам.
- SQLite — лучше для больших объёмов и сложных запросов, но здесь добавит ненужную сложность.
- Серверное хранилище — обеспечивает синхронизацию, но противоречит выбранному автономному сценарию.

## Решения и поведение

- Использовать существующий Flutter-проект и его Material UI.
- Хранить задачи как список объектов с уникальным идентификатором, текстом и статусом выполнения.
- При запуске восстановить список из локального хранилища; после добавления, выполнения или удаления сохранять актуальное состояние.
- Не добавлять пустые задачи. Пустой список должен иметь понятное сообщение и приглашение добавить первую задачу.
- Добавить проверки для списка задач и ключевых пользовательских действий.

## Проверка

- Запустить форматирование, анализатор и тесты проекта.
- Проверить пользовательский сценарий через доступный UI-инструмент на запущенной целевой платформе; если платформа недоступна, отметить проверку как SKIPPED или BLOCKED, не заявляя её успешной.
